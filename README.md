# Ctrl + ₸ — автопостинг в Threads

Каждый час GitHub Actions запускает `post.py`. Скрипт публикует в Threads (@ctrl.tenge)
самый ранний пост из `posts.json`, время которого уже наступило (время Алматы).

- `posts.json` — очередь постов: `id`, `date` (ГГГГ-ММ-ДД), `time` (ЧЧ:ММ, Алматы), `text` (до 500 знаков).
- `state.json` — что уже опубликовано (заполняется автоматически).
- Ключ Threads продлевается сам раз в неделю (хранится зашифрованным в `th_token.enc`).
- Перед публикацией скрипт проверяет, что ключ от аккаунта ctrl.tenge.

Секреты репозитория: `THREADS_TOKEN` (ключ Threads для ctrl.tenge), `ENC_KEY` (любой длинный пароль).
Тест без публикации: Actions → Threads autopost → Run workflow → dry = 1.
